What is Git, what is Github, and what is the difference between the two?
- Git is a version control system that tracks each version of a project.

- Github is a website that stores and track project files.
-The difference between Git and Github is that Git is a control system that tracks versions while Github is a website that stores and tracks project files.

What is the difference between a local repository and a remote repository?
-The difference between local repo is saved on the computer in storage (Github Desktop) while remote repo is in the cloud Github.com

What does the push command do in Git?
-The push command uploads changes from the local repo to the remote repo.

What does the commit command do in Git?
-The commit command saves file changes on only local changes

What is Github Desktop, & why are we using it?
-Github Desktop is a desktop app that allows you to use both Git and Github without using git commands. We are using Github Desktop because it is solely an app on desktop and we use it for submitting and doing assignments.
